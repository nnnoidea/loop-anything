# 网页工作台使用说明

网页用于查看、配置和操作平台。Agent 通过平台工具读写同一份数据；关闭网页不会停止后台平台或正在执行的任务。

## 阅读、轻量修改与启动 Loop

网页以阅读和运行操作为主，Loop 构建与复杂修改由 Agent 使用平台工具完成。从 Loop 库进入「查看与轻量修改」，默认查看整体流程。切换到节点详情可阅读职责、完整输入输出契约、数据来源与去向、事件规则、Skill；打开实现方案可查看命令、工作目录、prompt、等待条件、完整状态矩阵与配置。Loop 手册、验收场景、任务模板、参数映射和包文件均保留只读查看。

「轻量修改」可改名称、简短描述和已声明且已有值的简单默认输入；对象、列表及复杂契约保持只读。实现详情可把已有方案设为默认。修改自动保留到同一草稿；「保存」校验并更新本机可用版本，仅供新运行使用，已有 Run 保持启动时版本。

增删节点、连接端口、改模板和条件、编辑命令、Skill、脚本、参数契约及状态机由 Agent 完成。「交给 Agent 修改」提供草稿定位信息和 Skill 下载，不自动启动新 Agent。完整定义可查看和下载，包文件可阅读，导入导出继续可用。

从 Loop 进入启动准备，为本次运行选择输入、执行方案及通知出口。准备信息会保存；明确启动后才创建 Run。暂停／恢复、回答询问、结果查看及原会话恢复等运行操作继续保留。

## 查看过程与结果

运行页的任务图和列表展示实际 Task、依赖和等待原因。选中任务后，可从执行记录选择某次尝试，查看参数、输入来源、实现、生命周期和转移历史。

每张任务卡片提供“查看结果”，按执行尝试展示正式输出、文件和失败信息；查看不会重新执行任务。平台按结果结构展示文本、字段和表格，文件结果支持预览或下载。重试保留原 Task 和历次尝试，新一轮安排会产生新 Task。

## Agent 会话

在任务的执行尝试中选择“查看实时输出”或“打开交互终端”。普通命令提供只读输出；交互终端连接正在运行的同一 CLI，可补充要求、回答提问或发送 Ctrl+C。关闭面板不会停止进程，重新打开可继续查看。

候选实现选择“交互终端”后，主机需支持 PTY；目前支持 macOS/Linux。CLI 的模型、登录、权限及工具配置由使用者负责。终端文字不代替正式结果提交。

Agent 卡片可打开或恢复对应会话。恢复面板可核对原生 session ID、工作目录、本次要求和恢复命令；没有已记录 ID 时须提供真实身份。Run 必须仍在运行或暂停，CLI 自身的会话文件须保留。旧进程状态未知时，先在主机确认进程及其子进程停止，再使用“已确认旧进程停止”。

## 通知与回复

侧栏“通知出口”管理当前平台的命名出口。启动准备页可选择本次出口；运行页显示实际出口，并提供“修改出口”和“通知安排与记录”。改变某次运行的选择不会改变其他 Run。

“任务关系”展示等待条件和通知标记，“执行状态机”展示所选实现的实际矩阵。通知安排列出节点、状态或事件、条件和消息；实际通知记录包含脚本与 Agent 临时发出的消息及投递结果。“通知与控制”可调整通知、暂停等安排。

询问可以直接在网页回复，也可以让聊天中的 Agent 代为提交。询问本身不一定暂停运行，需要等待答案的步骤会显示对应等待条件。通知显示已送达不代表用户已读；失败或结果未知时，先核实再重试。

## 配置多机协作

打开“Agent 通信”，先配置各机器已挂载的共享空间，再发现并显式加入或创建群组。加入群组不会自动开放本机 Agent。

页面分别显示机器 ID 和当前工作区 ID。机器 ID 按需生成并保存在本机平台用户环境中；修改显示名称、重启或移动工作区不会改变它。同机多个工作区共享机器 ID，但任务寻址彼此独立。复制来的工作区会提示身份冲突；明确“为副本建立新工作区身份”后可开始新工作，复制过来的 Run 和请求仍是只读历史，不接管原执行。

配置具名 Agent 的命令、工作目录和恢复命令，填写主要任务说明并确认开放的群组。可仅开放本机调用，也可只调用别人。成员目录展示主要任务与可用状态；同名成员用机器和 Agent 身份区分。“复制加入说明”可供其他机器加入。

在具名 Agent 的“对应 Bot 的通知出口”中设置映射；原群中的确认和结果可优先由对应 Bot 发送，具体仍取决于已配置渠道能力。请求详情可查看状态、结果、日志和通知记录，也可取消或追问。暂停接单或退出群组默认保留已承接工作。

## 在网页中与 Agent 对话

“网页使用的 Agent”可沿用已有候选或配置自己的命令、工作目录、超时与唤醒提示词；这份配置与节点实现独立。准备阶段先讨论输入与方案，明确要求启动后才创建运行；运行中可选择操作范围并要求调整后续工作。

每条消息调用一次配置的本机命令，回复在命令退出后整体显示。业务事实以 Timeline 为准；从终端或飞书继续同一 Run 时，无需搬运网页聊天历史。平台自动给该入口限定工具地址和操作范围。

## cc-connect 与 Bot

在“通知出口”的“本机 cc-connect 接入”填写运行中桥接实际配置文件，可执行文件可留空从 PATH 查找。保存后列出 Bot。具名 Agent 编辑时可直接选择 Bot，无需先建通知出口；固定发送群才添加 cc-connect 出口并选择 Bot 和会话。数据目录从配置读取，可填写绝对路径覆盖；此操作不启动或重启 cc-connect。
