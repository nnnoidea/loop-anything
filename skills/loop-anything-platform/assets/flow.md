## 整体流程

```flow TB
(明确目标) -> 制定方案: 需要探索
明确目标 -> 执行任务: 方案已确定
制定方案 -> 执行任务: 提交参数
执行任务 -> 分析结果: 结果齐备
分析结果 -> 制定方案: 继续下一轮
分析结果 -> (结束): 目标已达成
```

## 怎样继续与结束

用真实业务替换示例节点和关系。对照 Loop 定义逐一画出全部节点，包括初始化、按需分支和异常兜底；不能用一个汇总框替代多个真实节点。写清下一轮如何安排、什么条件下结束，以及异常交给谁处理。
